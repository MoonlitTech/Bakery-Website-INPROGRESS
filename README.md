# Lolly Bloom Bakery Website

A simple bakery website created to practice and improve web development skills. The project currently focuses on building the homepage, with additional pages and features planned as development continues.

## Current Status
<mark>**In Progress**</mark>
<br>
The homepage is currently the main completed part of the project. Future updates will expand the website with additional pages, functionality, and responsive design improvements.

## Technologies Used 
* HTML
* CSS
* JavaScript

## Project Goals
The goal of this project is to practice building a website from scratch while improving my skills in HTML, CSS, and JavaScript.

## Current Features
This project currently has a few buttons, images, and forms, but currently they do not lead anywhere as I am still in the process of completing this project. The button shows "Coming Soon!" when clicked, but other than that the links are empty as of right now and the home page is the only one that is finished.
