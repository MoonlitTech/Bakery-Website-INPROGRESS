# Bakery Website Project Plan

## Project Overview

Build a simple, responsive bakery website that allows visitors to learn about the bakery, view the menu, learn about the bakery, and contact the business. 

## Website Pages

* **Home** — Introduce the bakery and provide an overview of the website.
* **Menu** — Display available bakery items and their descriptions.
* **About** — Provide information about the bakery and its story.
* **Contact** — Provide contact information and ways to reach the bakery.
* **Form** — Allow customers to submit feedback, rating, or other information.
